# Security policy

## Supported versions

Vaayil receives security fixes on the **latest release only**. Older releases are not
patched; update to the latest version before reporting an issue you found there.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting:

https://github.com/ATGPlatforms/vaayil/security/advisories/new

Please do not open a public issue for a suspected vulnerability, and do not include
secrets — WireGuard private keys, preshared keys or tokens — in a report.

Include the affected app version, the Android version and device, steps to reproduce,
and the impact you believe the issue has. Confirmed reports are fixed in a release and
credited in its notes unless you ask to stay anonymous.
